# Sample Data Directory

This directory will contain structured sample email datasets for KNIT's initial MVP (Phase 4).

The sample dataset will mirror the normalized schema expected from real Gmail data, including:
- Internship announcements & invitations
- Interview schedules & assessments
- College and academic notifications
- Project & assignment deadlines
- Personal correspondence
- Marketing and newsletter promotions
- System updates
- Suspicious and phishing simulation examples

*Real Gmail data is never stored here and will be connected securely in Phase 10.*
